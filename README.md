# Redesign Anmeldung Screen

A React and TypeScript interface redesign for an Anmeldung (registration) screen. The repository includes a district-based date filter for office listings.

## Current recorded feature

- Filter offices by district and date. The latest recorded project change adds date filtering to the office-by-district section.

## Tech stack

- React 18, TypeScript, Vite
- Tailwind CSS and Radix UI components

## Run locally

Prerequisites: Node.js and npm.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
